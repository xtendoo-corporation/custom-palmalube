=====================================
Palmalube Survey Report
=====================================

Este módulo añade un informe imprimible para las respuestas de encuestas.

**Funcionalidades:**

* Genera un informe en formato PDF de las respuestas de una encuesta.
* Muestra las respuestas en formato de tabla con dos columnas:
  - Primera columna: Pregunta (question_id)
  - Segunda columna: Respuesta (display_name)
* Utiliza el template de documentos de ventas (external_layout) para mantener la coherencia visual con otros documentos de la empresa.
* Incluye información del participante, fecha de respuesta y puntuación (si aplica).

**Uso:**

1. Navegar a una respuesta de encuesta (Survey > Participations).
2. Hacer clic en el botón "Imprimir" y seleccionar "Survey Responses Table".
3. Se generará un PDF con las respuestas en formato tabla.

**Instalación:**

Este módulo depende de:
- survey
- web
