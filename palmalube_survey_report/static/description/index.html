# Palmalube Survey Report ## Descripción Este módulo añade un informe imprimible profesional para las respuestas de encuestas en Odoo. ## Características - **Formato de Tabla**: Las respuestas se muestran en un formato de tabla limpio y legible - **Dos Columnas**: - Pregunta: Muestra el título de la pregunta y su descripción (si existe) - Respuesta: Muestra la respuesta del participante - **Template Profesional**: Utiliza el mismo diseño que los documentos de ventas (external_layout) - **Información Completa**: Incluye datos del participante, fecha y puntuación - **Gestión de Preguntas Omitidas**: Indica claramente las preguntas que fueron omitidas ## Instalación 1. Copiar el módulo en el directorio de addons personalizados 2. Actualizar la lista de módulos 3. Instalar el módulo "Palmalube Survey Report" ## Uso 1. Ir a **Survey > Participations** 2. Abrir una respuesta de encuesta 3. Hacer clic en **Imprimir > Survey Responses Table** 4. Se generará un PDF con las respuestas en formato tabla ## Créditos **Autor**: Palmalube **Licencia**: AGPL-3
