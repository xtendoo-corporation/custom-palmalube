This module integrates **Maintenance** with **Surveys** to enforce post-service quality control checklists.

**Features:**

* Assign surveys to maintenance requests
* Require survey completion before closing requests in specific stages
* Auto-fill surveys from equipment defaults
* Track survey completion status with badges
* Smart button to view survey responses
* Activity notifications for pending surveys

Configuration
=============

1. **Create a Survey**

   * Go to *Surveys > Surveys*
   * Create a new survey with questions for post-service quality control
   * Example: "Machinery Post-Service Checklist"

2. **Configure Maintenance Stages**

   * Go to *Maintenance > Configuration > Stages*
   * Mark stages where survey is required (e.g., "Post-Service Validation")
   * Check the "Require Survey" field

3. **Set Default Survey on Equipment (Optional)**

   * Go to *Maintenance > Equipments*
   * Open an equipment record
   * In the "Quality Control" section, select a default survey
   * This survey will be auto-assigned to new maintenance requests

Usage
=====

**Creating a Maintenance Request:**

1. Go to *Maintenance > Maintenance > Maintenance Requests*
2. Create a new request
3. Select equipment (survey auto-fills if equipment has default)
4. Or manually select a survey in "Post-Service Control" section

**Completing the Survey:**

1. Open the maintenance request
2. Click "Start Survey" button
3. Complete the survey questions
4. Submit the survey

**Moving Between Stages:**

* If a stage requires a survey and it's not completed, you'll see a warning banner
* The system will prevent moving to that stage until survey is completed
* Once completed, the status badge turns green

**Viewing Survey Responses:**

* Click the "Survey" smart button to view the response
* Survey responses are linked to the maintenance request
