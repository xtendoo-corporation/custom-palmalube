Este módulo añade una relación entre los equipos de mantenimiento y los clientes (res.partner).

**Características:**

* Añade el campo "Cliente" (partner_id) en el modelo maintenance.equipment
* Permite asociar un cliente a cada equipo de mantenimiento
* Filtra solo clientes (customer_rank > 0)
* Campo con tracking para seguimiento de cambios
* Añade el campo en las vistas formulario, árbol y búsqueda
* Permite agrupar equipos por cliente en la vista de búsqueda

Usage
=====

Para usar este módulo:

1. Vaya a Mantenimiento > Equipos
2. Abra o cree un equipo
3. En el formulario, verá el nuevo campo "Cliente"
4. Seleccione el cliente asociado al equipo
5. En la vista de lista, puede ver la columna "Cliente" (opcional)
6. En la búsqueda, puede filtrar por cliente y agrupar por cliente
